App settings

General

These belong to this app on this computer. Everything about you and your servers lives in each server's own settings.

Launch at login Open Stoop when you sign in to this computer.
Keep running when the window closes Closing the window leaves Stoop in the menu bar and voice keeps going. Quit from there.

Notifications

What is allowed to interrupt you, on every server you have open in this app.

Do not disturb Holds every banner, and sets do not disturb on every server here so everyone sees it on your dot. Turning it off here turns it off on them all.
Desktop notifications A native banner when someone mentions you, whichever server it was. Off here means no banners from any of them.
Check they arrive Nothing? Your computer keeps its own switch for Stoop, in the system's notification settings.

Voice

How calls behave on every server you have open in this app.

Voice room sounds A soft tone when someone joins or leaves the call you're in, whichever server it's on. Off here silences it on all of them.
Push to talk While you're muted in a call, hold Ctrl+` to talk, from any app. Letting go mutes you again.
Allow Input Monitoring Input Monitoring is used only to listen for the global push to talk keys. Switch Stoop on in Privacy & Security → Input Monitoring, then quit and reopen Stoop.

Appearance

How Stoop looks in this app. Every server you open here wears it, and so do the app's own screens. A server opened in a browser keeps the theme chosen there.
